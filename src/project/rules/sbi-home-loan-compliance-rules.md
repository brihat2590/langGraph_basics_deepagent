# SBI Home Loan Compliance Rules (Official SBI)

**Source:** State Bank of India – Home Loan Application Form & Most Important Terms and Conditions (MITC)

**Version:** September 2026

---

## 1. Applicant Eligibility

| Rule ID    | Compliance Rule                                                                  | Severity |
| ---------- | -------------------------------------------------------------------------------- | -------- |
| SBI-HL-001 | Applicant must be a Resident Indian (or eligible NRI for NRI Home Loan).         | Critical |
| SBI-HL-002 | Minimum age at application: **18 years**.                                        | Critical |
| SBI-HL-003 | Loan should generally be liquidated before borrower reaches **70 years** of age. | Critical |

---

## 2. Identity & KYC Compliance

| Rule ID    | Compliance Rule                                                      |
| ---------- | -------------------------------------------------------------------- |
| SBI-HL-004 | PAN is mandatory.                                                    |
| SBI-HL-005 | Aadhaar or another valid identity proof is required.                 |
| SBI-HL-006 | Valid address proof must be submitted.                               |
| SBI-HL-007 | Passport-size photographs are required for applicants/co-applicants. |

---

## 3. Income Verification

| Rule ID    | Compliance Rule                                                      |
| ---------- | -------------------------------------------------------------------- |
| SBI-HL-008 | Latest salary slips must be submitted for salaried applicants.       |
| SBI-HL-009 | Form 16 / Income Tax Returns must be submitted where applicable.     |
| SBI-HL-010 | Bank statements supporting income must be provided.                  |
| SBI-HL-011 | Self-employed applicants must submit business income documents/ITRs. |

---

## 4. Property Compliance

| Rule ID    | Compliance Rule                                                     |
| ---------- | ------------------------------------------------------------------- |
| SBI-HL-012 | Property title/legal ownership documents must be submitted.         |
| SBI-HL-013 | Approved building plan must be available.                           |
| SBI-HL-014 | Construction/modification must follow local authority approval.     |
| SBI-HL-015 | Property valuation/legal verification is mandatory before sanction. |

---

## 5. Loan Usage Compliance

| Rule ID    | Compliance Rule                                                                                                                                             |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| SBI-HL-016 | Loan must be used only for approved housing purposes (purchase, construction, extension, repair, renovation, plot, interiors/furnishings where applicable). |
| SBI-HL-017 | Any deviation in approved construction plan requires authority approval.                                                                                    |

---

## 6. Credit & Disclosure Compliance

| Rule ID    | Compliance Rule                                                       |
| ---------- | --------------------------------------------------------------------- |
| SBI-HL-018 | Applicant authorizes SBI to verify information through third parties. |
| SBI-HL-019 | Applicant consents to CIBIL/RBI-authorized credit bureau reporting.   |
| SBI-HL-020 | Applicant declares all submitted documents are true and accurate.     |

---

## 7. Security & Insurance Compliance

| Rule ID    | Compliance Rule                                                                                    |
| ---------- | -------------------------------------------------------------------------------------------------- |
| SBI-HL-021 | Mortgage/security over financed property is required unless alternate security is accepted by SBI. |
| SBI-HL-022 | Comprehensive property insurance covering fire, flood, earthquake etc. is required after sanction. |
| SBI-HL-023 | SBI has the right to inspect the financed property.                                                |

---

## 8. Loan-to-Value (LTV) Compliance

| Rule ID    | Compliance Rule                                           |
| ---------- | --------------------------------------------------------- |
| SBI-HL-024 | Loan up to ₹30 lakh → Maximum LTV **90%**.                |
| SBI-HL-025 | Loan above ₹30 lakh up to ₹75 lakh → Maximum LTV **80%**. |
| SBI-HL-026 | Loan above ₹75 lakh → Maximum LTV **75%**.                |

---

## 9. Consent & Communication Compliance

| Rule ID    | Compliance Rule                                                             |
| ---------- | --------------------------------------------------------------------------- |
| SBI-HL-027 | Applicant agrees to receive SMS/phone/email updates on application status.  |
| SBI-HL-028 | Applicant must notify SBI if mobile number or address changes.              |
| SBI-HL-029 | Applicant acknowledges reading and accepting SBI MITC before loan sanction. |
